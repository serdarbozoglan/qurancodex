Mimari Seçim: Overlay mi, Sayfa mı?

Mevcut proje mimarisi ile uyum ve kullanıcı deneyimi açısından en kritik karar

A

Fullscreen Overlay (Mevcut Pattern)

Tüm mevcut araçlar (Melekler, KavimlerAtlası, CennetCehennem) bu pattern'i kullanıyor. Navbar'daki "Keşfet" menüsünden açılıyor. URL değişmez. Browser back ile kapanıyor. React Router gerektirmiyor. Lazy-loaded Suspense ile code-split.

✓ Avantajlar

  • Mevcut tüm kodla %100 uyumlu
  • Hızlı uygulama
  • Navbar entegrasyonu hazır
  • Back button desteği var

✗ Dezavantajlar

  • URL paylaşılamıyor
  • Tarayıcı geçmişinde değil
B

Ayrı Sayfa + React Router

/kuranin-renkleri gerçek bir URL olur. React Router DOM eklenir. App.jsx yeniden yapılandırılır. Tüm mevcut overlay'ler route-based sisteme taşınır (veya ikili bir mimari kurulur).

✓ Avantajlar

  • Gerçek URL — paylaşılabilir
  • SEO potansiyeli
  • Derin link desteği

✗ Dezavantajlar

  • React Router kurulumu gerekir
  • App.jsx büyük refactor
  • Mevcut 30+ overlay ile uyumsuzluk riski
  • Çok daha uzun süre

Öneri

A — Overlay öneriyorum. Mevcut mimariyle tam uyumlu, uygulama süresi çok kısa, kullanıcı deneyimi zaten kanıtlanmış. Spec'teki /kuranin-renkleri URL referansı muhtemelen kavramsal — gerçek route değil. Navbar'ın "Keşfet" menüsünden açılması spec'te açıkça belirtilmiş.
